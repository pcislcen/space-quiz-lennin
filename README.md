# Órbita — Cuestionario espacial

Órbita es un cuestionario interactivo en español sobre exploración espacial. Incluye diez preguntas de opción múltiple, explicaciones para las respuestas y un resultado final según la puntuación. La interfaz se adapta al tema claro u oscuro del sistema y funciona sin dependencias externas.

## Ejecutar localmente

No requiere instalación ni compilación. Abre `index.html` directamente en un navegador para jugar.

## Publicación

GitHub Actions publica el contenido estático de este repositorio en GitHub Pages cada vez que se actualiza la rama `main`. El flujo también se puede iniciar manualmente desde la pestaña **Actions**.
